👾 拼豆桌宠 (Bead Pet) - 下载即玩说明 👾
==================================================

欢迎下载拼豆桌宠！为了让您可以“解压即玩”，我们已经为您配置好了自动启动脚本。

📌 准备工作 (只需一次)
--------------------------------------------------
因为这是一个基于最新现代网页技术 (React + Express) 构建的全栈应用，您的电脑上需要安装 Node.js 运行环境：

1. 访问 Node.js 官网：https://nodejs.org/
2. 下载并安装任意一个版本（推荐选择左侧的 "LTS 长期支持版"，一路点击下一步完成安装即可）。
3. 安装完成后，您就可以在无需打开任何黑窗口/终端的情况下，通过以下简单方式一键运行了！

🚀 快速启动方法
--------------------------------------------------
【Windows 用户】：
1. 双击运行文件夹根目录下的： 启动游戏_Windows.bat
2. 脚本会自动为您检测环境、下载必要组件（仅第一次需要约30秒），并自动在浏览器中打开游戏页面。

【Mac 用户】：
1. 双击运行文件夹根目录下的： 启动游戏_Mac.command
2. 如果提示权限问题，可以先打开终端运行一次以下命令赋予其双击运行权限：
   chmod +x ./启动游戏_Mac.command
3. 脚本会自动启动并在默认浏览器中为您打开桌宠空间。

💡 额外玩法与特色
--------------------------------------------------
- 自定义桌宠：点击上传任何你喜欢的图片 (如自推、喜爱的卡通人物等)，应用将运用独特的像素拼豆算法将它转化为可爱的拼豆实体！
- 自由漫步与作息：开启“自由漫步”后，桌宠会在屋里走来走去，中午会按时午睡，晚上会陪你熬夜，早上还会晚起哦。
- 互动护理：请注意经常跟它互动！长期不玩会肚子饿，不投喂点心或者陪它玩耍的话，饱腹感降到 0 会饿晕倒喔！
